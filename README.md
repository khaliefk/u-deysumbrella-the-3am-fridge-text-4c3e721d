One line a smart fridge texts its owner at 3am, written for the [make.fun bounty](https://make.fun/bounty/u-deysumbrella-the-3am-fridge-text-4c3e721d).

## The line

> 3am. You opened me, stared into the light like it owed you money, and left empty-handed. We both know you will be back in ten minutes.

## How it works

`main.py` writes that single line to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt` when set). No network, no secrets, no dependencies, just the standard library.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
